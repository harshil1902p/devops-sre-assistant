# Kafka CommitFailedError: group has already rebalanced - how to fix?

**Tags:** consumer-lag, kafka, messaging, rebalance

## Question
Python kafka consumer keeps failing commits with
`CommitFailedError: Commit cannot be completed since the group has already rebalanced`.

## Accepted Answer
Your processing loop exceeds `max_poll_interval_ms`. Lower `max_poll_records`, speed up processing,
or raise the interval. Make processing idempotent since messages will be redelivered.

## Comments
> Lowering max_poll_records from 500 to 50 fixed it immediately.
