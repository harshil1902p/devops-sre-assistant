# redis-py 'TimeoutError: Timeout reading from socket' but Redis is up

**Tags:** cache, latency, redis, sessions, slowlog

## Question
Our Python API logs `redis.exceptions.TimeoutError: Timeout reading from socket` a few times an hour.
`redis-cli ping` works. Network looks fine. What is going on?

## Accepted Answer
The client connected but didn't get a reply within `socket_timeout`. Usually Redis was **blocked** by
a slow command (KEYS, big DEL, Lua) or by persistence forks on a memory-constrained host. Check
`SLOWLOG GET` and `INFO persistence` (`latest_fork_usec`). Use SCAN/UNLINK and make cache calls fail-safe.

## Comments
> Our culprit was BGSAVE forking a 12 GB instance; moving to AOF on a replica fixed it.
