# Python requests SSL: CERTIFICATE_VERIFY_FAILED certificate has expired

**Tags:** cert-manager, certificates, letsencrypt, security, tls

## Question
Suddenly all calls to our API fail with `CERTIFICATE_VERIFY_FAILED certificate has expired`.

## Accepted Answer
Check the served certificate dates with openssl. If expired, renew it. Never disable verification (`verify=False`)
as a fix. If the leaf is valid, an intermediate in the chain might have expired.

## Comments
> Our intermediate CA expired; re-issuing the chain fixed it.
