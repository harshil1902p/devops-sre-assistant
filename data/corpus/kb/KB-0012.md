# Java heap space OOM in container even though the pod has 2Gi

**Tags:** gc, heap, java, jvm, memory

## Question
Why do I get `java.lang.OutOfMemoryError: Java heap space` when my pod limit is 2Gi and usage is 700Mi?

## Accepted Answer
The JVM's default max heap is 25% of container memory. Set `-XX:MaxRAMPercentage=70-75`. If the pod is
instead killed with exit 137, that is container OOMKilled, a different problem.
