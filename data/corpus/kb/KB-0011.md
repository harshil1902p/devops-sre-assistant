# Should my Kubernetes liveness probe check the database?

**Tags:** cascading-failure, health-checks, kubernetes, probes

## Question
Is it a good idea for the liveness endpoint to verify the database connection?

## Accepted Answer
No. If the DB blips, all pods fail liveness and get restarted together, amplifying the outage. Check
dependencies in the readiness probe (pod is removed from Service endpoints but not killed).

## Comments
> Learned this the hard way during a DB failover.
