# Post-mortem INC-2025-0031: TLS certificate expired - x509 certificate has expired

| Field | Value |
|---|---|
| Date | 2025-01-19 |
| Service | `api-gateway` |
| Environment | production |
| Severity | SEV1 |
| Duration | 41 minutes |

## Summary
Public API unavailable over HTTPS for 41 minutes. Trigger: WAF rule blocked ACME HTTP-01 challenges; renewal silently failed for 30 days.

## Detection
Synthetic probes and customer reports.

## Timeline (UTC)
- 00:00 Certificate expires.
- 00:05 Probes fail with certificate has expired.
- 00:41 WAF exception added, certificate renewed.

## Error Signatures Observed
```text
ssl.SSLCertVerificationError: [SSL: CERTIFICATE_VERIFY_FAILED] certificate verify failed: certificate has expired (_ssl.c:1006)
cert-manager: Failed to create Order: 403 urn:ietf:params:acme:error:unauthorized: Invalid response from http://api.contoso.com/.well-known/acme-challenge/
```

## Root Cause Analysis
**Trigger:** WAF rule blocked ACME HTTP-01 challenges; renewal silently failed for 30 days.

cert-manager failed to renew because the HTTP-01 challenge path was blocked by a new WAF rule; the
certificate expired 30 days later.

## Resolution
Renewal + expiry alerting + DNS-01.
