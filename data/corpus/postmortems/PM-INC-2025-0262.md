# Post-mortem INC-2025-0262: Azure OpenAI 429 Too Many Requests - rate limit exceeded

| Field | Value |
|---|---|
| Date | 2025-07-22 |
| Service | `sre-assistant` |
| Environment | staging |
| Severity | SEV3 |
| Duration | 35 minutes |

## Summary
Assistant responses failed for 35 minutes during nightly evaluation. Trigger: Shared TPM quota between batch evaluation and live traffic.

## Detection
Error-rate alert on the assistant API.

## Timeline (UTC)
- 01:00 Nightly evaluation starts on shared deployment.
- 01:02 429s on interactive requests.
- 01:35 Evaluation moved to a separate deployment.

## Error Signatures Observed
```text
openai.RateLimitError: Error code: 429 - {'error': {'code': '429', 'message': 'Requests to the ChatCompletions_Create Operation under Azure OpenAI API version 2024-10-21 have exceeded token rate limit of your current OpenAI S0 pricing tier. Please retry after 6 seconds.'}}
```

## Root Cause Analysis
**Trigger:** Shared TPM quota between batch evaluation and live traffic.

Deployment Tokens-Per-Minute (TPM) quota exceeded because an eval job and live traffic shared one deployment,
and prompts included very large contexts.

## Resolution
Separate deployments and backoff.

## Action Items
| # | Action | Status |
|---|---|---|
| 1 | Token budget per request (owner: AI team). | Open |

## Lessons Learned
Treat LLM quota as a capacity resource with isolation and budgets.
